# Eng Path

A comprehensive English learning platform built with Next.js and Convex, providing interactive dialogues, speaking feedback, and writing assessment tools to help learners master practical English skills at their own pace.

## Tech Stack

- **Frontend**: Next.js 15+ with React 19
- **Backend**: Convex for real-time data sync and serverless functions
- **Styling**: Tailwind CSS with custom UI components
- **Authentication**: Convex Auth integration
- **Audio**: Google Cloud Text-to-Speech for dialogue synthesis

## Getting Started

### Prerequisites

- Node.js 18+
- npm or yarn

### Installation

```bash
npm install
```

### Development

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to see the application.

## Project Structure

- `app/` - Next.js application pages and layouts
- `components/` - Reusable React components
- `convex/` - Backend functions and database schema
- `context/` - Project documentation and guidelines
- `hooks/` - Custom React hooks
- `lib/` - Utility functions
- `scripts/` - Build and generation scripts
