# Product

## Register

product

## Users

Currently the developer/owner using the tool for personal TOEFL preparation. Designed with scale in mind: a motivated adult learner working through a structured English curriculum at their own pace, likely self-directed and returning daily or near-daily for study sessions and flashcard reviews.

## Product Purpose

Eng Path is a personal English learning platform for TOEFL preparation. It delivers a complete, pre-generated curriculum across four CEFR levels (A1–B2), combining grammar instruction, reading, listening, writing, speaking, and spaced-repetition vocabulary review in a strict module sequence. AI evaluates writing and speaking in real time. The product succeeds when a user can complete a full A1–B2 arc and feel ready for the TOEFL exam.

## Brand Personality

Warm, grounded, motivating.

Warm and encouraging without being loud. The interface should feel like a well-designed notebook — cream pages, subtle warm borders, a reliable tool you return to daily. Inviting you in, celebrating small wins, and staying out of the way while you actually learn. Emotionally: confidence through consistency, not gamification pressure.

The visual palette reinforces this directly: warm cream backgrounds, subtle warm-gray borders, orange for the moments that matter (primary actions, progress), and sage teal for calm precision (focus rings, accents). Light and dark modes are supported — the dark mode keeps the same warm brown undertone, never going cold.

Reference feel: Notion's calm, readable surfaces. The same quiet confidence, the same content-first clarity. Not Duolingo's streak anxiety — not Anki's utilitarian gray. A focused workspace with warmth baked in.

## Anti-references

- **Generic SaaS / startup template** — Intercom/HubSpot blue-and-white corporate design. This product has warmth and personality; it should never feel like enterprise software.
- **Dense LMS (Moodle, Canvas)** — Cluttered, bureaucratic, institutional. Every screen should have clear breathing room and a single primary action.
- **Flashcard-only tools (Anki)** — Utilitarian to the point of being cold. Even the flashcard interface should feel considered and rewarding to use.

## Design Principles

1. **Content is the hero.** Learning material — passages, exercises, dialogue — should command visual focus. UI chrome is infrastructure; it should be invisible when the user is in flow.
2. **Progress is a feeling, not a number.** Completion indicators and feedback exist to motivate, not surveil. Celebrate effort without manufacturing urgency or anxiety.
3. **Friendly precision.** The interface is warm and approachable, but every element earns its place. Playfulness comes from considered choices — color, weight, motion — not decoration.
4. **Trust the learner.** No nagging, no streak pressure, no dark patterns. The product respects that the user chose to be here and gives them the tools to move at their own pace.
5. **Scale-ready from day one.** Design decisions should work equally well for one user and a thousand. Avoid UI patterns that only make sense for a personal tool (e.g., hard-coded names, admin shortcuts in the main flow).

## Accessibility & Inclusion

No strict WCAG level required. Aim for reasonable color contrast and keyboard navigability as a baseline. Respect `prefers-reduced-motion` for any animations or transitions.
