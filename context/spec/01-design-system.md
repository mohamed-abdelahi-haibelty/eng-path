Read `AGENTS.md` before starting.

We are adding the design system and UI primitive components.

Install and configure `shadcn/ui`.

Add these shadcn components:

- Button
- Card
- Dialog
- Input
- Tabs
- Textarea
- ScrollArea
- Sonner
- RadioGroup
- Label
- Tooltip
- Skeleton
- Sidebar
- Breadcrumb
- Separator
- ScrollArea
- Badge
- Avatar
- Progress

Do not modify the generated `components/ui/*` files after installation

Also Install `lucide-react`

Create `lib/utils.ts` with a reusable `cn()` helper for merging tailwindcss classes.

Modify the `global.css` to match the style in the `ui-context.md`.

### Check when done

- All components import without errors
- `cn()` works properly
